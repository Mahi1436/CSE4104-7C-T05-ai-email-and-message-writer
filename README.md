## 🎯 3. Project Objectives

The main objectives of this project are:

- ✉️ To generate complete emails and messages from short ideas.
- 🎨 To allow users to customize messages by selecting purpose, tone, and length.
- 💬 To suggest suitable replies to received messages.
- 📝 To correct grammatical errors and improve users' existing drafts.
- 🌐 To support Bangla and Banglish input for English message generation.
- 📂 To save generated drafts so users can access and reuse them later.
- 💡 To provide a simple, responsive, and user-friendly writing assistant.
- 🚀 To help users communicate more professionally and confidently.

---

## 🚀 4. Features

The application will provide the following features:

### 🔐 4.1 User Authentication

- User registration with full name, email, and password.
- Secure login and logout functionality.
- Forgot password and password recovery through email.
- Secure access to private user accounts.

### ✍️ 4.2 AI Message Writer

- Generate complete emails and short messages from simple ideas.
- Support both Email and Short Message generation.
- Automatically generate appropriate email subjects and message bodies.
- Allow users to edit generated content before copying.
- Copy generated messages with one click.
- Regenerate messages to receive alternative versions.
- Support ideas of up to 1000 characters.

### 🎛️ 4.3 Purpose, Tone, and Length Options

Users can customize generated messages according to their communication needs.

**📌 Purpose:**

- Application
- Request
- Follow-up
- Complaint
- Apology
- Thank You
- Job Application

**🎭 Tone:**

- Formal
- Professional
- Friendly
- Persuasive

**📏 Length:**

- Short
- Medium
- Detailed

### ⚡ 4.4 Quick Refine

Users can improve generated messages using one-click options:

- ✂️ Make Shorter
- 🎩 More Formal
- 😊 Friendlier
- 📝 Fix Grammar

### 💬 4.5 Smart Reply

- Users can paste a received email or message.
- Select their preferred reply tone.
- Generate 2–3 different reply suggestions.
- Select, edit, and copy suitable replies.

### 🧠 4.6 AI Proofreading

- Check spelling and grammatical errors.
- Improve sentence structure and clarity.
- Provide three proofreading levels:
  - Fix Mistakes Only
  - Fix and Improve
  - Rewrite Professionally
- Highlight changes in corrected text.
- Display a list of changes made to the original text.

### 🌏 4.7 Bangla and Banglish Input Support

- Allow users to express their ideas in Bangla or Banglish.
- Convert Bangla and Banglish input into polished English emails or messages.
- Help users who are not confident writing in English.

### 📚 4.8 Draft History

- Save generated messages to personal history.
- View previously generated emails and messages.
- Search and filter saved drafts.
- Open, copy, and delete saved drafts.
- Permanently delete all personal draft history.

### 👤 4.9 User Profile

- Maintain personal profile information.
- Save and update full name, designation, institution, ID, and phone number.
- Set default writing tone and output language.
- View and manage personal account information.

### 🛡️ 4.10 Admin Panel

- Provide a separate admin login and dashboard.
- View total registered users.
- Monitor the number of generated messages.
- View active users and failed AI requests.
- Monitor statistics for today, the last 7 days, and the last 30 days.
- Search registered users by name or email.
- Block, unblock, and delete user accounts.
- Monitor system activities and AI usage.

> 🔒 **Privacy:** Administrators can view usage statistics and counts but cannot read users' private message content.

## 🧰 5. Technology Stack

The project will use modern web technologies and AI integration tools to develop a reliable and responsive application.

| 🎨 Frontend | React.js |

### 🔍 Technology Overview

- **React.js:** Used to develop the interactive and responsive user interface.
- **Vite:** Provides frontend development tooling and build support.

- **Express.js:** Provides backend routing and API development.

## ⚙️ 7. Project Setup Instructions

Follow these instructions to set up and run the project locally.

### 📋 7.1 Prerequisites

Make sure the following tools are installed on your computer:

- [🟢 Node.js](https://nodejs.org/) (LTS recommended)
- npm (comes with Node.js)
- [🟠 Git](https://git-scm.com/)
- [🔵 Visual Studio Code](https://code.visualstudio.com/)
- MongoDB Atlas account
- Google Gemini API key

Verify Node.js and npm installation:

```bash
node -v
npm -v
```

Verify Git installation:

```bash
git --version
```

### 📥 7.2 Clone the Repository

Open a terminal and clone the project repository:

```bash
git clone https://github.com/Mahi1436/CSE4104-7C-T05-ai-email-and-message-writer.git
```

Navigate to the project directory:

```bash
cd CSE4104-7C-T05-ai-email-and-message-writer
```

Open the project in VS Code:

```bash
code .
```

### 🔧 7.3 Backend Setup

Navigate to the backend directory:

```bash
cd backend
```

Install backend dependencies:

```bash
npm install
```

Create a `.env` file inside the `backend/` directory and configure the required environment variables according to the backend implementation.

**📄 Example configuration:**

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secure_jwt_secret
GEMINI_API_KEY=your_google_gemini_api_key
```

Add the required SMTP configuration if the password recovery feature uses email delivery.

> ⚠️ **Important:** Use the actual environment variable names expected by the backend source code. Never commit real API keys, passwords, database credentials, or secrets to GitHub.

Start the backend development server:

```bash
npm run dev
```

If the project does not have a `dev` script, use the start command defined in `backend/package.json`.

### 💻 7.4 Frontend Setup

Open a new terminal from the project root and navigate to the frontend directory:

```bash
cd frontend
```

Install frontend dependencies:

```bash
npm install
```

Create a frontend `.env` file if required by the Vite configuration.

**📄 Example:**

```env
VITE_API_URL=http://localhost:5000
```

Use the correct backend URL and environment variable name required by the frontend implementation.

Start the frontend development server:

```bash
npm run dev
```

Vite will display a local URL in the terminal, usually:

```text
http://localhost:5173
```

Open the displayed URL in your browser to access the application.

### 🗄️ 7.5 Database Configuration

1. Create a MongoDB Atlas account.
2. Create a new MongoDB cluster.
3. Configure database access credentials.
4. Allow your development IP address in Network Access.
5. Copy the MongoDB connection string.
6. Add it to the backend `.env` file as required.
7. Start the backend and verify that the database connection is successful.

### 🤖 7.6 Gemini API Configuration

1. Visit [Google AI Studio](https://aistudio.google.com/).
2. Generate a Gemini API key.
3. Add the API key to the backend environment file.
4. Ensure the backend uses the official Google Gen AI SDK.
5. Test the API using a sample prompt before integrating it with the frontend.

> 🔐 **Security:** Gemini API credentials must remain on the backend. Do not expose the API key in frontend source code or public repositories.

### ▶️ 7.7 Running the Project

For local development, both servers must be running.

| Application | Command | Local URL |
|---|---|---|
| 🖥️ Backend | `npm run dev` | `http://localhost:5000` |
| 🌐 Frontend | `npm run dev` | `http://localhost:5173` |

Run each command from its respective `backend/` or `frontend/` directory.

### 🧯 7.8 Troubleshooting

- **Node/npm not recognized:** Reinstall Node.js and restart your terminal.
- **Port already in use:** Change the port in the environment configuration.
- **MongoDB connection error:** Verify the connection string, credentials, and IP allowlist.
- **Gemini API error:** Check the API key, API access, quota, and backend configuration.
- **Frontend cannot connect to backend:** Verify the API URL and backend server status.
- **Missing dependencies:** Run `npm install` inside the affected directory.

## 🎯 10. Project Scope and Limitations

### 🟢 In Scope

- Responsive web application for desktop and mobile browsers.
